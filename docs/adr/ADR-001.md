# ADR-001: Redpanda sebagai broker stream lokal (tanpa platform cloud)

- Status: Diterima
- Tanggal: 2026-11-21
- Pembuat: SkyPulse Data Platform Team

## Konteks
Proyek memerlukan sumber *batch* **dan** sumber *stream* dengan `event_time` dan `event_id`
unik. Spesifikasi tugas menetapkan platform harus tetap on-premise/lokal; managed cloud
tidak boleh menggantikan komponen inti. Tim membutuhkan replikasi, offset, dan replay
tanpa bergantung pada layanan eksternal.

## Keputusan
Gunakan Redpanda (API Kafka) di Docker, topik `flight-raw-stream` dan `flight-stream-dlq`,
dengan `acks=all`, `retries=3`, partition key = `icao24`. Producer juga menulis
`data/bronze/flight_events_raw.jsonl` sebagai *source of truth* sebelum publish.

## Alternatif
- Kafka + Zookeeper: lebih kompleks untuk demo satu mesin.
- Managed Kafka (Confluent Cloud): melanggar kebutuhan local-only.
- Polling API langsung ke consumer: tidak ada replay/offset, sulit membuktikan F-05/F-13.

## Dampak
+ Replay bisa dilakukan dari broker *atau* dari Bronze JSONL (`--replay-bronze`).
+ Consumer menyimpan offset secara eksplisit dan dedup di SQLite.
- Operasi perlu memantau health broker dan ukuran topik; batas resource 768 MB ditetapkan.
