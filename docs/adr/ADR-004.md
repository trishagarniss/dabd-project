# ADR-004: Dataset ML dari BTS asli + tracking eksperimen lokal

- Status: Diterima
- Tanggal: 2026-11-21

## Konteks
Spesifikasi **melarang data sintetis**. Versi awal proyek menghasilkan fitur dan label
menggunakan `np.random`, yang tidak dapat diterima. Label harus berasal dari rekaman
penerbangan asli dan dapat diaudit.

## Keputusan
- Sumber: BTS TranStats On-Time Performance Januari 2024 (US Government / public domain),
  diunduh sekali, checksum SHA-256 disimpan di `data/bronze/bts_ontime_provenance.json`.
- `src/ml/prepare_features.py` hanya **memuat** `data/gold/flight_delay_features.parquet`;
  tidak ada pembangkitan baris maupun label secara acak.
- Eksperimen v1 (Ridge baseline), v2 (RandomForest), v3 (GradientBoosting) memakai
  test set yang sama (`seed=42`, `test_size=0.2`).
- Tracking memakai `src/ml/tracking.py` (JSONL + file per run) sebagai pengganti MLflow
  lokal: run_id, hyperparameter, metrik, dataset_version, code_version, artifact path.

## Alternatif
- MLflow server: butuh layanan tambahan dan storage; belum perlu untuk skala demo.
- Synthetic telemetry: melanggar F-11.

## Dampak
+ Champion dipilih otomatis berdasarkan RMSE terendah dan dicatat di `data/gold/model_registry.json`.
+ API membaca *champion* secara dinamis, bukan hardcoded ke model tertentu.
- Perlu mengunduh BTS sekali saat persiapan (zip 25 MB).
