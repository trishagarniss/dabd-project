# ADR-004: Dataset ML daripada BTS sebenar + tracking eksperimen tempatan

- Status: Accepted
- Tarikh: 2026-11-21

## Konteks
Spesifikasi **melarang data sintetik**. Versi awal projek menjana ciri dan label
menggunakan `np.random`, yang tidak boleh diterima. Label mesti daripada rekod penerbangan
sebenar dan boleh diaudit.

## Keputusan
- Sumber: BTS TranStats On-Time Performance Jan 2024 (US Government / public domain),
  dimuat turun sekali, checksum SHA-256 disimpan di `data/bronze/bts_ontime_provenance.json`.
- `src/ml/prepare_features.py` hanya **memuat** `data/gold/flight_delay_features.parquet`;
  tiada penjanaan rawak baris mahupun label.
- Eksperimen v1 (Ridge baseline), v2 (RandomForest), v3 (GradientBoosting) menggunakan
  test set sama (`seed=42`, `test_size=0.2`).
- Tracking guna `src/ml/tracking.py` ( JSONL + fail per run ) sebagai pengganti MLflow
  tempatan: run_id, hyperparameter, metrik, dataset_version, code_version, artifact path.

## Alternatif
- MLflow server: perlu servis tambahan dan storage; belum perlu untuk skala demo.
- Synthetic telemetry: melanggar F-11.

## Kesan
+ Champion dipilih automatik oleh RMSE terendah dan direkod di `data/gold/model_registry.json`.
+ API membaca *champion* secara dinamik, bukan hardcoded ke model tertentu.
- Perlu muat turun BTS sekali semasa persediaan (25 MB zip).
