# ADR-005: RBAC 3 peranan + observability tempatan dengan alert webhook

- Status: Accepted
- Tarikh: 2026-11-21

## Konteks
API mendedahkan data penerbangan dan inference. Perlu buktikan viewer gagal pada aksi
admin/operator, secret tidak disimpan dalam Git, dan 3 alert dapat diuji hingga
notifikasi serta clear.

## Keputusan
- `.env.example` mengandungi placeholder; `.env` (di-gitignore) mengandungi kunci demo.
  FastAPI membaca `FDP_API_KEY_*` dan URL / organisasi guna `x-api-key`.
- Peranan `viewer < operator < admin` (`ROLE_RANK`). `POST /api/v1/ml/predict-delay`
  memerlukan `operator`; perubahan skema/audit hanya `admin`.
- Audit JSONL di `logs/audit.jsonl` untuk setiap request yang diautentikasi.
- Prometheus + Alertmanager + Grafana + node-exporter + webhook receiver berjalan
  dalam Docker network `backend` / `frontend`. Port sensitif (broker, DB) tidak
  dibuka ke `frontend`.
- Tiga alert: BatchJobFailed, StreamLagOrFreshnessHigh, ServiceResourceUnhealthy
  dengan threshold/window/severity/owner/runbook di `monitoring/prometheus/alert_rules.yml`.

## Alternatif
- TLS + SSO: di luar skop demo; risiko dicatat dalam `docs/SECURITY.md`.
- Alert terus ke e-mail: sukar diaudit dalam repo; webhook JSONL lebih mudah dibuktikan.

## Kesan
+ Ujian 401/403 dan log audit boleh diulang dengan pytest.
- Demo ini **tidak** sesuai untuk pendedahan internet; hanya `localhost` / Docker internal.
