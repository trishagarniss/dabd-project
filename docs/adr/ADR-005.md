# ADR-005: RBAC 3 peran + observability lokal dengan alert webhook

- Status: Diterima
- Tanggal: 2026-11-21

## Konteks
API mengekspos data penerbangan dan inference. Perlu dibuktikan bahwa viewer gagal pada
aksi admin/operator, secret tidak disimpan di Git, dan 3 alert dapat diuji hingga
notifikasi serta clear.

## Keputusan
- `.env.example` berisi placeholder; `.env` (di-gitignore) berisi kunci demo.
  FastAPI membaca `FDP_API_KEY_*` dan URL / organisasi memakai `x-api-key`.
- Peran `viewer < operator < admin` (`ROLE_RANK`). `POST /api/v1/ml/predict-delay`
  membutuhkan `operator`; perubahan skema/audit hanya `admin`.
- Audit JSONL di `logs/audit.jsonl` untuk setiap request yang terautentikasi.
- Prometheus + Alertmanager + Grafana + webhook receiver berjalan di Docker network
  `backend` / `frontend`. `node-exporter` tersedia lewat profile opsional `host-metrics`
  karena mount `/` ditolak Docker Desktop di Windows. Port sensitif (broker, DB) tidak
  dibuka ke `frontend`.
- Tiga alert: BatchJobFailed, StreamLagOrFreshnessHigh, ServiceResourceUnhealthy
  dengan threshold/window/severity/owner/runbook di `monitoring/prometheus/alert_rules.yml`.

## Alternatif
- TLS + SSO: di luar lingkup demo; risiko dicatat dalam `docs/SECURITY.md`.
- Alert langsung ke e-mail: sulit diaudit dalam repo; webhook JSONL lebih mudah dibuktikan.

## Dampak
+ Uji 401/403 dan log audit dapat diulang dengan pytest.
- Demo ini **tidak** cocok untuk eksposur internet; hanya `localhost` / Docker internal.
