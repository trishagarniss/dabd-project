# ADR-003: Satu aliran medallion untuk batch dan stream, dengan quality gate

- Status: Diterima
- Tanggal: 2026-11-21

## Konteks
Dua sumber (OurAirports + BTS batch, OpenSky stream) harus bertemu di mart yang sama
agar use case "flight delay + live traffic" tetap koheren. Data stream memiliki duplikat
dan event terlambat; data batch memiliki perubahan kode bandara dari waktu ke waktu.

## Keputusan
- Bronze = raw + checksum + batch_id; Silver = normalisasi + dedup + DLQ; Gold = mart +
  feature store. Semua ditulis oleh `src/common/storage.py`.
- `config/quality_rules.json` mengatur not-null / range / unique / cross-dataset.
  Baris gagal dikarantina ke `silver.dlq_events`; publikasi Gold ditolak jika
  `pass_ratio < 0.95`.
- Temuan cross-dataset dicatat sebagai **peringatan**, bukan penghalang: contoh `PBI`
  (Jan 2024) kini bernama `DJT` di OurAirports terkini.

## Alternatif
- Pipeline terpisah untuk stream dan batch: mart bertentangan, sulit direkonsiliasi.
- Quality gate yang langsung membuang baris: tidak ada bukti DLQ untuk audit.

## Dampak
+ 50 baris dengan kode lama tetap dipakai dengan peringatan yang terlihat di laporan.
+ Replay dari Bronze menghasilkan Silver/Gold yang sama (idempoten).
- Perlu peninjauan berkala terhadap pemetaan kode IATA/ICAO (dokumen kualitas).
