# ADR-003: Satu aliran medallion untuk batch dan stream, dengan quality gate

- Status: Accepted
- Tarikh: 2026-11-21

## Konteks
Dua sumber (OurAirports + BTS batch, OpenSky stream) mesti bertemu di mart yang sama
supaya Use Case "flight delay + live traffic" koheren. Data stream mempunyai Duplicate
dan event lewat; data batch mempunyai perubahan kod lapangan terbang dari semasa ke semasa.

## Keputusan
- Bronze = raw + checksum + batch_id; Silver = normalised + dedup + DLQ; Gold = mart +
  feature store. Semua ditulis oleh `src/common/storage.py`.
- `config/quality_rules.json` mengawal not-null / range / unique / cross-dataset.
  Baris gagal dikarantina ke `silver.dlq_events`; tolak penerbitan Gold jika
  `pass_ratio < 0.95`.
- Cross-dataset findings direkod sebagai **amaran**, bukan halangan: contoh `PBI`
  (Jan 2024) kini bernama `DJT` dalam OurAirports semasa.

## Alternatif
- Pipeline berasingan untuk stream dan batch: mart bercanggah, sukar reconciliasi.
- Quality gate yang membuang terus baris: tiada bukti DLQ untuk audit.

## Kesan
+ 50 baris dengan kod lama kekal digunakan dengan amaran yang kelihatan dalam laporan.
+ Replay dari Bronze menghasilkan semula Silver/Gold yang sama (idempoten).
- Perlu semakan berkala terhadap pemetaan kod IATA/ICAO (dokumen kualiti).
